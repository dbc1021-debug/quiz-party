# 🎀 可愛搶答派對（GitHub Pages + Firebase 免費版）

網頁放在 **GitHub Pages**，即時連線和題庫交給 **Google Firebase**。
不用自己的伺服器、不會休眠，同學用手機任何網路（4G／5G／任何 Wi-Fi）掃 QR Code 就能玩。

---

## 一次性設定（約 20 分鐘）

### 1. 建立 Firebase 專案
1. 到 <https://console.firebase.google.com> 用 Google 帳號登入 →「建立專案」
2. 專案名稱隨意（例：quiz-party），Google Analytics 可以關掉

### 2. 新增網頁應用程式，取得設定
1. 專案首頁按 **</>（網頁）** 圖示，暱稱隨意，**不用**勾選 Firebase Hosting
2. 畫面會出現一段 `firebaseConfig = { apiKey: ..., ... }`
3. 打開這個資料夾裡的 **`js/firebase-config.js`**，把那幾行換成你的
4. 同一個檔案裡的 `ADMIN_EMAILS` 改成**你的 Google 帳號**

> apiKey 放在網頁裡是正常的，資料安全靠下面第 4 步的「安全規則」保護。

### 3. 開啟登入功能
左側選單「建構 → **Authentication**」→「開始使用」→「登入方式」，啟用兩個：
- **匿名**（學生用，不用註冊）
- **Google**（老師登入後台用）

### 4. 建立資料庫並貼上安全規則
1. 左側「建構 → **Firestore Database**」→「建立資料庫」
2. 位置選 **asia-east1（台灣）**，速度最快（建立後不能改）
3. 選「以正式版模式啟動」
4. 建好後點上方「**規則**」分頁，把畫面上的內容**全部刪掉**，貼上這個資料夾裡 **`firestore.rules`** 的內容
5. 把裡面的 `your.name@gmail.com` 換成你的 Google 帳號 → 按「**發布**」

### 5. 上傳到 GitHub Pages
1. 到 <https://github.com> 建立新的儲存庫（例：quiz-party），選 **Public**
2. 點「uploading an existing file」，把這個資料夾**裡面**的所有檔案和資料夾拖進去（index.html、admin.html、js、css…），按「Commit changes」
3. 儲存庫的「**Settings → Pages**」：Source 選「Deploy from a branch」，Branch 選 **main**、資料夾 **/(root)** → Save
4. 等 1～2 分鐘，網址會是：`https://你的帳號.github.io/quiz-party/`

> 程式碼公開沒關係：題目和答案都存在 Firebase，不在 GitHub 上。

### 6. 允許 GitHub 網址登入
回到 Firebase「Authentication → **設定** → **已授權網域**」→「新增網域」→ 填 `你的帳號.github.io`

### 完成！🎉
- 後台：`https://你的帳號.github.io/quiz-party/admin.html`
- 學生不用記網址，掃大螢幕的 QR Code 就好

## 上課流程
1. 打開後台，用 Google 登入
2. 「題庫與匯入」→ 下載範本、填好、匯入（記得填分類）
3. 「建立遊戲」→ 選題（最多 50 題）→ 設定每題秒數 → 選風格 → 設定自動進行 →「開始遊戲」
4. 會開新分頁「主持畫面」，按「⛶ 全螢幕」投影；**遊戲中請不要關掉這個分頁**（不小心關掉可以按瀏覽器「上一頁」或從歷史紀錄重新打開，進度不會不見）
5. 名單出現後按「開始遊戲」。預設會**自動進行**：時間到 → 公布答案（停 5 秒）→ 排行榜（停 5 秒）→ 下一題，最後自動出現頒獎台
   - 停留秒數可在後台調整；排行榜填 0 就不顯示，直接下一題
   - 全班都答完會提早結束這題，不用等時間到
   - 想講解某一題時按「⏸ 暫停自動」，講完再按「▶ 繼續自動」或右邊按鈕
   - 如果取消勾選「時間到自動進入下一題」，就改成每一步都由老師按按鈕（也可以按空白鍵）

## 免費額度夠用嗎？
Firebase 免費方案每天有 50,000 次讀取、20,000 次寫入（台灣時間大約下午 3～4 點重置）。

| 一場遊戲 | 大約用掉的讀取次數 |
|---|---|
| 120 人 × 50 題 | 約 25,000（每天可玩約 2 場） |
| 120 人 × 20 題 | 約 10,000（每天可玩約 5 場） |
| 40 人 × 20 題 | 約 3,500 |

超過額度當天會無法連線，隔天自動恢復，**不會被收費**（除非你自己升級付費方案）。
可以在 Firebase 主控台「Firestore → 用量」查看。

歷史紀錄頁有「🧹 清除 1 天前的遊戲作答資料」，偶爾按一下可以節省資料庫空間（排名紀錄會保留）。

## Excel 格式
後台可下載範本（也就是這個資料夾的 `template.xlsx`）。

| 題型 | 題目 | 閱讀文本 | 選項A～F | 正確答案 | 秒數 | 解析 |
|---|---|---|---|---|---|---|
| 單選 | 台灣最高的山？ | | 玉山／雪山… | A | 20 | |
| 多選 | 哪些是哺乳類？ | | 鯨魚／企鵝／蝙蝠… | A,C | 30 | |
| 素養 | 最晚可以待到幾點？ | 【圖書館公告】… | 13:00／13:30… | B | 45 | |
| 翻譯 | 「蘋果」的英文？ | | Apple／Banana… | A | 15 | |
| 翻譯 | 把「謝謝你」翻成英文 | | （不填） | thank you\|thanks | 25 | |

- 翻譯題**不填選項**就是打字作答，多個可接受答案用 `|` 分隔（不分大小寫、忽略標點）
- 秒數可空白，之後在後台設定；有問題的列會告訴你第幾列、什麼原因

## 常見問題
- **後台按登入沒反應／跳錯誤**：檢查第 3 步有沒有啟用 Google、第 6 步有沒有加授權網域
- **後台顯示「沒有權限」**：`firebase-config.js` 和 `firestore.rules` 裡的 Email 要一模一樣，規則要按「發布」
- **學生加入時說名稱有人用**：換一個名稱即可
- **修改程式或設定後沒變化**：GitHub Pages 更新要等 1～2 分鐘，手機可以重新整理

## 🎰 扭蛋機（單機版，不需要 Firebase）
上傳到 GitHub 後打開 `https://你的帳號.github.io/quiz-party/gacha.html` 就能用。
- 平板用 Safari／Chrome 打開後選「加入主畫面」，就像 App 一樣全螢幕
- 左下角 ⚙️ 進設定（預設密碼 0000，進去後請改掉）：獎品、數量、機率、圖片、顏色
- **指定大獎**：同學點「轉一下」前，輕點右下角淡淡的 ♡（變成 ♥），下一次就會轉出大獎
- 設定和紀錄只存在那台平板的瀏覽器裡；換平板前先用「匯出設定檔」備份
